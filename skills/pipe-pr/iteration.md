# Commentaire d'itération d'une PR mise à jour

Tous les commits poussés depuis la dernière mise à jour de la PR, dans ce format :

```markdown
## Mise à jour — [date]

### Nouveaux commits
- `emoji type(scope): description`

### Changements ajoutés
- `chemin/fichier` — ce qui a changé

### Impact
Une phrase pour l'ensemble de l'itération.
```
